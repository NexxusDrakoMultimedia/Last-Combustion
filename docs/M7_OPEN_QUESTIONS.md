# M7 open questions for the final polish

Every design question raised while building M7 (story and fog of war, 0.3.0) that has not been settled for good. Go through this page before the milestone's release: answer each one, change the game or the Game Design Document where the answer differs from what is built, and delete the row. A row that is only waiting for the owner says so.

How to read it. **Taken** means a default was built (usually the recommendation in [the M7 plan](M7_PLAN.md)) and the owner has not yet confirmed it. **Open** means nothing is built or the answer is not known. **Owner** means only the project owner can decide it. The plan says what is built; this page says what is still undecided.

## D. Problems found that need a decision

| #   | Problem                                                                                                                                                                                                                                                                                                                                                                                           | Proposal                                                                                                                                                 | Status |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| D1  | A career that has just been created and the same career after a save and reload settle different money for the computer garages (about 2.96 million against 6.23 million in one test round). A load, a visit to a garage in the Registry and a season rollover give the computer garages their businesses, and a new career has none until then. A save and reload should never change the world. | Give every computer garage its business when the career is created. This changes the world for new careers only, because saves already get them on load. | Owner  |
| D2  | The stop-every-day switch lasts only for the session.                                                                                                                                                                                                                                                                                                                                             | Keep it with the other settings once there is a place for them.                                                                                          | Open   |

Saving after every step could make saves slow or big.                                                                                                                                                                                                                                       | Measure the size of `race_state` and the time to save in the browser, and trim what is stored if it is too large.                                        | Open   |

## F. Release steps (owner only)

The steps are in [Releasing](RELEASING.md). For M7, remember:

1. A beta after each slice (`0.3.0-beta1`, `0.3.0-beta2` and `0.3.0-beta3`), each a version bump, a tag and a pre-release, with no changelog section of its own.
2. Before 0.3.0, the full documentation pass: every claim checked against the code, the "built so far" notes merged into the sections they belong to, the new files included (`CONTRIBUTING.md`, `CONTRIBUTORS.md`, `CODE_OF_CONDUCT.md`, `AGENTS.md`), and screenshots taken from the release.
3. Check that a save from 0.2.x loads and plays a whole season (migrations 54 to 63 add the rivalry, story, news, ghost, scout, head of scouting, car inspection, race state and race plan tables).
4. Turn `[Unreleased]` in `CHANGELOG.md` into the dated 0.3.0 entry, as one list of everything new since 0.2.0.
5. Read through every fog screen as a new player: the hover text, the "not known" cases, and whether a clear fog is worth the scouts' wages.
