## AI coding assistants

Parts of the code, tests and documents were written with AI coding assistants, mainly Claude by Anthropic, working from the instructions in [AGENTS.md](AGENTS.md) and reviewed by the maintainers. A commit made this way says so in a `Co-Authored-By` line. An assistant is a tool the maintainers use, not a person with rights over the project: the licence and the code of conduct apply to the work in the same way.

## How to be listed

When your first pull request is merged, add one line for yourself in the Contributors list above, in the same pull request or the next one:

```text
- [your-github-handle](https://github.com/your-github-handle): what you did, in a few words
```

List your GitHub handle only. Do not add your real name, an email address or any other personal detail, and do not add anyone else's. This is the same rule that keeps real people out of the game's data and text (see [CONTRIBUTING.md](CONTRIBUTING.md)). If you would rather not be listed, say so in your pull request and a maintainer will leave you out.

Every contribution counts, not only code: bug reports with a seed that reproduces them, playtesting notes, corrections to the documents, balance suggestions backed by numbers, and reviews. A maintainer can add you for work that does not come as a pull request.
